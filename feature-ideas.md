## Keyboard Shortcuts

**Description:** Power-user hotkeys for fast chart navigation without mouse.

**Proposed bindings:**
- `1`–`6` — Switch timeframe (1m / 5m / 15m / 1h / 4h / 1D)
- `E` / `V` / `R` — Toggle EMA / VWAP / RVOL
- `L` — Toggle levels (PDH/PDL/ODC/ORB)
- `S` — Toggle support & resistance
- `F` — Fit content (reset zoom to show all data)
- `/` — Focus symbol input
- `Esc` — Close any open modal/dropdown

**Notes:**
- Should only fire when no input is focused (avoid conflicts with symbol typing)
- Consider a help overlay (`?` key) listing all shortcuts
- Reference: TradingView, ThinkOrSwim both have extensive hotkey systems
