## 1. Security — Grade: A

### Passed

- Server-side proxy model — API keys never reach browser (no `VITE_` prefix on secrets)
- SSRF guard via `new URL().hostname` exact match in `api/bars.js` + `api/snapshot.js`
- Rate limiting on all 3 API endpoints:
  - `ws-auth`: 5 requests/IP/min
  - `bars`: 60 requests/IP/min
  - `snapshot`: 30 requests/IP/min
- TTL cleanup every 2 minutes + 10K entry cap on rate limiters
- No `dangerouslySetInnerHTML`, `eval()`, or `Function()` anywhere in codebase
- CSP + HSTS + X-Frame-Options + X-Content-Type-Options + Permissions-Policy configured
- localStorage schema validation on all persisted data (`src/utils/validate.js`, 29 tests)
- URL param regex validation before applying to state (`src/hooks/useURLState.js`)
- ErrorBoundary sanitizes errors in production, shows raw only in dev
- Timing-safe bearer token comparison (`api/ws-auth.js`)
- `.env` gitignored, `.env.example` committed with placeholders only
- No hardcoded API keys, tokens, or secrets found in source

### Findings

| Severity | Issue | Location |
|----------|-------|----------|
| MEDIUM | Rate limiter is per-serverless-instance — bypassable via Vercel horizontal scaling. Documented as "best-effort per instance" | `api/bars.js:27-44`, `api/snapshot.js:22-38`, `api/ws-auth.js:35-51` |
| MEDIUM | `VITE_WS_AUTH_TOKEN` ships in client bundle. Documented as non-secret — rate limiting is the real gate | `src/services/websocket.js:23` |
| LOW | `snapshot.js` reflects validated symbol in error message (`Invalid symbol: ${sym}`). Validated input, but violates minimal-disclosure principle | `api/snapshot.js:68` |
| LOW | Timing-safe comparison has length check before constant-time compare — minor, since all tokens are fixed-length UUIDs (36 chars) | `api/ws-auth.js:18-22` |
| LOW | `api/bars.js` error message lists valid timeframes — not sensitive (public API spec) | `api/bars.js:73` |

### Recommendation

Upgrade rate limiting to persistent KV (Upstash Redis or Vercel KV) for true per-IP enforcement if moving to real-money trading or expecting significant traffic.
